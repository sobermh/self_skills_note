# 运行时契约

## 保留宿主职责

- 使用已安装宿主的公共工具注册、执行、配置和生命周期 API，检查实际导出，不只看声明。
- 被编译擦除的类型使用 type-only import，对声明支持的宿主版本验证运行时导入。类型存在不代表运行时导出存在。
- 保持原执行链中的审批、作用域、guard、参数校验、超时、取消、并发分类和后处理。
- 保留原始工具身份、结构化内容、二进制或图片附件、呈现元数据、延迟上下文与完成标记。文本成功不等于原生结果正确。
- 状态归属清晰，隔离 Agent 和会话；卸载时清理监听器、计时器与资源。使用受支持的历史 API 恢复持久状态，必要时适配宿主 snapshot API。
- 不把错误、取消、缺依赖或空结果悄悄转成成功。可能计费或修改状态的操作，前次结果未知时不盲目重试；支持时按任务 ID 恢复。

## 渐进式工具经验，仅在相关时使用

工具发现改变可见性，不改变授权。搜索失败不能证明能力不存在，应提供目录浏览或精确名称加载作为补救。
调用新发现工具前，模型必须获得完整定义和关联说明，不依赖在同一并行批次内先发现再调用。
如果保留原生协议能解决通用兼容问题，就不要把所有插件绕进文本代理或增加媒体专属绕过规则。

声称节省 token 时，说明任务集、模型、请求次数、缓存命中、未缓存输入和输出。
合成任务成功不能证明通用能力提升或费用下降，长会话可能最终加载全部工具。

## 验证证据

对修改边界测试正常、错误和取消路径。涉及宿主 API 时加入真实依赖契约测试，旧 mock 结构不能发现所有上游变化。
界面显示缺陷既检查结果结构，也检查真实宿主界面。明确标记未执行的界面或安装测试。

## 内置插件与外层构建适配

插件自身测试通过不能证明产品构建适配仍兼容。修改内置插件的导入、宿主语言字段、托盘注册或公开入口后，检查外层 staging 覆盖、启动校验及关联构建测试；只跑受影响模块，不默认重新制作安装包。

截取源码并在 VM 中执行的测试必须提供该片段实际依赖的函数和宿主字段。例如托盘标签新增 `updateMessages(locale)` 后，测试夹具也要注入真实文案函数与语言，不能保留旧的无依赖片段假设。文案可本地化，但菜单分发应保持稳定的命令 id，并验证适用语言下的注册和调用。

用户授权更新外层时，对齐真实子模块 HEAD、product.json 的版本/提交及受影响的生成快照，遵守外层路径约束并保留其他插件的已有改动。只允许本地更新时，不提交、不推送，也不擅自暂存。若校验读取 Git 索引而本地指针尚未暂存，可用隔离的临时索引验证实际工作区；明确区分该验证与默认索引校验，不能把临时索引中的值当作已提交的引用。
